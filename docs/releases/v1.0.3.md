What's new in BilaiTube 1.0.3

- The app checks for updates every time it opens and shows the update card, so nobody misses a new version
- The update downloads only once: after you allow installs from BilaiTube and come back, the install starts by itself
- If you'd rather not allow installs from BilaiTube, the update card links to the GitHub download
- Videos and Shorts start faster: playback begins with less buffering, and the next Shorts, Up Next and the videos on screen in Home are prepared ahead of time
- Like and dislike use filled icons with a small animation, and the counts change with your tap

The in-app updater installs this over 1.0.2.
