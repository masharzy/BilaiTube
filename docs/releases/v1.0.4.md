What's new in BilaiTube 1.0.4

- "Check for updates" no longer says you're on the latest version when GitHub couldn't be reached
- The update check falls back to github.com when GitHub's API limit is hit (common on mobile networks that share one IP), so new versions are still found
- Update checks no longer use cached answers

The in-app updater installs this over 1.0.3.
